## 3. Дашборд

Чотири метрики: MT-01/MT-02 дають спонсору строк і незакриті ризики;
MT-03/MT-04 дають PM чергу та потік із потрібними діями після межі.
Пороги — внутрішні управлінські сигнали, не статистично доведені норми;
обидва спонсорські сигнали червоні, але це не автоматичне рішення про запуск.
Не включено власні DORA: без деплоїв і інцидентів застосунку їх немає.
